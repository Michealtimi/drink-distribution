## TASK 3 — PRE-WRITTEN MESSAGES (BEST CONVERSION)

### WhatsApp — Universal (works for ~80%)

**First message (cold):**

```
Hello [Name],

I work with a beverage distribution team supplying energy drinks (Red Bull + alternatives) and event-focused drinks to businesses in Lagos/Abuja.

Most gyms, lounges, and event venues we speak with already have suppliers — but still experience stockouts during busy periods or last-minute demand.

We're not asking you to switch.

We simply support businesses as a reliable backup supplier for peak days and events.

Would you be open to a small, zero-risk trial delivery so you have an alternative when demand spikes?
```

**Follow-up (Day 3–5):**

```
Hi [Name], just following up on my message.

Even if you don't need anything now, we're happy to support as a backup supplier whenever demand increases.

Would you be open to a small, zero-risk trial delivery so you have an alternative when demand spikes?
```

**Why it works:** Acknowledges existing supplier; names real pain (stockouts); removes commitment; ends with soft yes/no.

## TASK 5 — CRM DATA MODEL (ZERO-BUDGET → APP)

### Google Sheets (starter columns)

| Column | Purpose |
|--------|---------|
| Business name | Lead/customer name |
| Segment | A / B / C or Nightlife, Event, Gym, Retail, Corporate |
| City | Lagos / Abuja |
| Contact name | Decision maker |
| Phone | Primary |
| Email | For offices/corporates |
| WhatsApp availability | Yes/No |
| Last contact date | Last message or call |
| Status | New / Contacted / Interested / Order Placed / Repeat |
| Notes | Credit terms, preferences, objections |

### How this maps to your app (Postgres / Prisma)

- **Lead** = one row (name, phone, email, city, category, status, source, notes).
- **Customer** = converted lead (same + deliveryDay, creditLimit).
- **Segment** = derived from **category** (CLUB/LOUNGE → Nightlife; EVENT_CENTER → Event; GYM → Gym; SMALL_RETAILER → Retail; OFFICE → Corporate).
- **Status** in app: SCRAPED → VERIFIED → MESSAGED → INTERESTED → CUSTOMER → REPEAT_CUSTOMER.
- **Last contact** = last follow-up or message date (you can add `lastContactedAt` to Lead later).
- **Follow-ups** = your existing FollowUp table (Day 2, Day 5, Month-end).

**Scaling:** Automated follow-ups = your cron + message generator. Analytics = your existing analytics/overview API (counts by status, city, category).

## TASK 6 — DISTRIBUTION & PARTNERSHIP STRATEGY

**Ideal partner distributor:**
- **Coverage** — Lagos and/or Abuja; areas you don’t reach.
- **Logistics** — vans, drivers, delivery windows.
- **Credit discipline** — collects on time; no long grace.
- **Stock reliability** — doesn’t run out of Red Bull on Friday.
- **Trade terms** — clear minimum order, payment terms.

**How to approach:** Lead with "backup supplier" and trial; show you don’t compete on every order. Offer: you take event/last-minute and peak backup; they keep regular routes.

**Value you offer:** Reliable backup; event-focused supply; one less stock-out risk for their accounts.

**Avoid:** Partners who over-promise credit, can’t deliver on time, or run out of stock often.

## TASK 7 — EXECUTION PRINCIPLES (REALITY-BASED)

| Principle | What it means |
|-----------|----------------|
| **Credit control** | Trial = pay after delivery (48 hrs). Repeat = cash or very short credit. You are not a bank. |
| **Weekend demand spikes** | Nightclubs order Thu–Fri. Have stock and delivery capacity; don’t promise what you can’t deliver. |
| **Stock-out risk** | Your promise is "backup when they run out." If you run out, you break trust. Manage your own stock. |
| **Trust & consistency** | Same contact, same delivery day, same terms. Builds repeat. |
| **Relationship management** | WhatsApp + follow-ups (Day 2, Day 5, month-end) keep you top of mind. |
| **Territory discipline** | Define areas (e.g. VI, Ikeja, Abuja Central) and stick to delivery days. |
| **Route-to-market** | Group customers by area and day; use your Routes module. Backup supplier = you fill gaps, not replace. |

## HOW THE SCRAPER & APP USE THIS

1. **Target segments in app** — Your `CustomerType` enum = segment. Map:
   - **Primary (A):** CLUB, LOUNGE → Nightlife; EVENT_CENTER → Event; GYM → Gym.
   - **Volume (B):** SMALL_RETAILER → Retail; add HOTEL/LIQUOR_STORE if you extend schema.
   - **Institutional (C):** OFFICE → Corporate.

2. **Scraper queries** — Use the keywords and segment names as queries, e.g.:
   - Lagos: "nightclub", "lounge", "event center", "gym", "energy drink supplier", "Red Bull distributor".
   - Abuja: same + "bar", "event venue".

3. **Message by segment** — First message and follow-up use:
   - **Universal** for GYM, SMALL_RETAILER, OFFICE, OTHER.
   - **Nightclub/Lounge** for CLUB, LOUNGE.
   - **Event planner** for EVENT_CENTER.

4. **CRM** — Leads/Customers with category + city + status = your pipeline. Notes = preferences, objections. Follow-ups = automated touchpoints.

The app is already built for this: scrapers feed leads, you validate, you send the segment-appropriate message (Universal / Nightclub / Event), mark messaged, follow-ups run. This doc defines the **who**, **what to say**, and **how to segment** so the scraper and messages stay aligned with real targets.

## How this is implemented in the app

| What | Where in code |
|------|----------------|
| **Segment groups (A/B/C)** and **which message variant** per lead category | `lib/segment-config.ts` — `CATEGORY_TO_GROUP`, `CATEGORY_MESSAGE_VARIANT` |
| **Suggested scraper queries** (nightclub, lounge, event center, gym, etc.) | `lib/segment-config.ts` — `SCRAPER_QUERIES_BY_SEGMENT`, `SCRAPER_QUERIES_ALL` |
| **Scraper UI** — one-click suggested queries | `app/scrapers/page.tsx` — "Target segments — suggested queries" box; clicking a chip fills the Query field |
| **Cold WhatsApp message (first contact)** | `lib/message-generator.ts` — `generateFirstMessage()` uses Universal / Nightclub / Event planner copy by lead category |
| **Follow-up message (Day 3–5)** | `lib/message-generator.ts` — `generateFollowUpMessage()` uses the short backup-supplier follow-up |
| **CRM** | Leads and Customers with `category` (maps to segment); status flow; Follow-ups table for Day 2, Day 5, month-end |

To change copy: edit the message strings in `lib/message-generator.ts`. To add or change segment queries: edit `lib/segment-config.ts` and the `SUGGESTED_QUERIES_*` arrays in `app/scrapers/page.tsx`.
